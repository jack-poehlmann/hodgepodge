### Microsoft SQL Server ###

https://hub.docker.com/_/microsoft-mssql-server

Windows PC:
docker run --name sqlserver2019 -e "ACCEPT_EULA=Y" -e "MSSQL_SA_PASSWORD=Adam123456" -p 1401:1433 -d mcr.microsoft.com/mssql/server:2019-latest

MacOS & Linux:
docker run --name sqlserver2019KinetEco -e 'ACCEPT_EULA=Y' -e 'MSSQL_SA_PASSWORD=Adam123456' -p 1401:1432 -d mcr.microsoft.com/mssql/server:2019-latest

# Note on MacOS computers with Apple Silicon processors, you will receive a warning message about the image's platform. The Docker container was created for Intel processors, but Apple's Rosetta emulation will correctly handle the translation. There is no need to be concerned about this message.

# Note that MSSQL_SA_PASSWORD and SA_PASSWORD are functionally identical. Microsoft has depreciated SA_PASSWORD but it continues to work. MSSQL_SA_PASSWORD should be used moving forward.

### Docker Commands ###

# view all running containers
docker ps

# view all containers regardless of status
docker ps -a

# stop a container
docker stop sqlserver2019

# start a container
docker start sqlserver2019

# remove a container
docker rm sqlserver2019
